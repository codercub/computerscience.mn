Асуулт хариулт

Түгээмэл асуултууд.

Шийдвэр гаргахын өмнө мэдэх ёстой зүйлс.

Программчлал яагаад бүх сурагчид хэрэгтэй вэ?+
Программчлал нь асуудал шийдвэрлэх чадвар, бүтээлч сэтгэлгээ, ерөнхий тооцооллын ур чадварыг хөгжүүлдэг — эдгээр нь ирээдүйд ямар ч мэргэжил сонгосон хэрэгтэй болох суурь ур чадвар юм.
Яагаад алгебрийн бэлэн байдал шаардлагатай вэ?+
Программчлал нь хийсвэрлэлийг (abstraction) шаарддаг тул алгебрт хэрэглэдэг "хувьсагч" гэдэг ойлголт программчлалын хувьсагчтай маш төстэй байдаг. Мөн график программчлалд заримдаа алгебрийн үндсэн мэдлэг шууд хэрэглэгддэг тул CMU энэ суурь шаардлагыг тавьсан байдаг.
Яагаад Python хэл дээр заадаг вэ?+
Python бол уншиж ойлгоход хялбар, дэлхийн коллеж болон салбарт хамгийн өргөн хэрэглэгддэг хэлүүдийн нэг. Иймд CS1-ийг дүүргэсэн сурагч цаашид коллежийн курс, бодит ажлын байранд шууд ашиглагдах чадвартай кодын хэлээр суралцсан байдаг.
Яагаад график дээр суурилсан курс вэ?+
График хөгжилтэй бөгөөд сурагчдад программчлалын бүтээлч талыг мэдрүүлж, өөрийн бичсэн кодын алдааг (bug) шууд нүдээр харж ойлгоход тусалдаг — энэ нь debug хийх чадварыг мэдэгдэхүйц хурдасгадаг.
Computer Science ба Programming ямар ялгаатай вэ?+
Computer science бол мэдээлэл, тооцооллын онолын болон шинжлэх ухааны хандлагыг судалдаг салбар, харин programming бол программ хангамжийг бодитоор зохион бүтээж, бичиж, турших гар практик ажил. CMU-ийн зүйрлэснээр: архитектор барилгын зураг төсөл гаргадаг бол барилгачин тэрхүү зурган дээр үндэслэн бодит барилгыг барьдагтай адил. CS1 хөтөлбөр programming дээр төвлөрдөг — өөрөөр хэлбэл шууд гараар хийж сурах хэсэг дээр анхаардаг.
Урьдчилсан кодчлолын мэдлэг шаардлагатай юу?+
Үгүй. CS1 бол суурь хөтөлбөр тул кодчлолын өмнөх мэдлэг шаардахгүй — ground-up аргачлалаар анхнаасаа зааж эхэлнэ. Гагцхүү англи хэл уншиж ойлгох, дунд шатны математикийн мэдлэгтэй байх шаардлагатай.
7-12-р ангиас өөр байвал яах вэ?+
Хөтөлбөр 7-12-р ангийн сурагчдад зориулагдсан. Хэрвээ онцгой бэлтгэлтэй сурагч байгаа бол бидэнтэй холбогдсоноор бид хүүхдийнх нь түвшинг тогтоох боломжтой.
Онлайнаар яаж суралцах вэ?+
Бие даан суралцах чадварын эзэмшсэн ахлах ангийн сурагчдын хувьд бид цаг алдахгүйгээр гэрээсээ суралцах боломжийг бүрдүүлсэн юм. Онлайн байснаар сурагч, багш хэн ч тусгай программ хангамж суулгах шаардлагагүй, Chromebook зэрэг ямар ч төхөөрөмж дээр ажиллах боломжтой платформ ашиглан, өөр өөр компьютер дээрээс ч ажлаа үргэлжлүүлэн хийх боломжтой байдаг давуу талтай.
Хичээл ямар хэлээр явагдах вэ?+
Лекц монгол хэл дээр явагдана. Код бичих, техникийн нэр томьёог англи хэлээр зааж сургана — учир нь CPCS болон цаашдын шатанд англи хэлний бэлэн байдал шаардлагатай болно. Хэрэв сурагч англиар тайлбар авах шаардлагатай бол англиар нэмэлт тайлбар өгнө.
Төлбөрөө хэсэгчлэн төлж болох уу?+
Тийм ээ, семестр тутамд хувааж төлөх боломжтой. Төлбөрийн нөхцөлийн талаар дэлгэрэнгүйг бүртгүүлэх үедээ тодруулна.
